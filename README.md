# Our Word at home

Daily English and Hungarian word puzzles for a household: 4, 5, and 6 letters, strict hard mode, saved scores, elapsed solve-time tiebreakers, and an optional live table.

Game: https://our-word-household.nemozoli.chatgpt.site

This repository contains native iPhone and Android hosts and their build workflow. See [mobile/README.md](mobile/README.md) for SideStore, Android APK, and home-screen installation details. The hosts use system browser views to preserve hosted sign-in. An internet connection is required.

The **Build SideStore IPA and Android APK** Actions workflow produces an IPA for SideStore re-signing and a debug APK for household sideloading. Builds need no Apple signing secrets.
